# My Blog - React Mini Project

This is a simple React blog that has:
- Post cards displayed from a `posts.json` file
- A search box to search posts by title
- Buttons to filter posts by category

## How to run
```
npm install
npm start
```

## Files
- `src/posts.json` - all the blog posts are here, you can add new posts
- `src/PostCard.js` - a component that displays a single post card
- `src/App.js` - all the main logic (search + filter)
- `src/App.css` - styling
